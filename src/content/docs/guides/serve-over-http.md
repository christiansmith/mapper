[`@christiansmith/mapper-http`](https://jsr.io/@christiansmith/mapper-http)
exposes a Mapper instance behind an HTTP endpoint: the deployment supplies
mappings and extensions, clients send input documents, the service returns
mapped output.

This guide is planned. Until it lands, see the package documentation.
:::
